# Decisions

## 2026-07-29 — Reading BrowserとReading Lensを別プロジェクトにする

**決定**  
Reading Lensを独立した製品、リポジトリ、コードベースとして管理する。

**理由**  
文章構造を扱うHTML Reading Browserと、画面座標を扱うオーバーレイでは技術構造と体験設計が異なるため。

## 2026-07-29 — v0.1ではOCRを使わない

**決定**  
座標ベースの移動でLens自体の感覚を検証する。

**理由**  
最初の問いは認識精度ではなく、周囲を隠し窓を動かすことが心理的圧迫と視線逸脱を減らすかどうかだから。

## 2026-07-29 — 自動移動を主役にしない

**決定**  
手動移動と自動移動を同等に試せるようにする。

**理由**  
自動移動がユーザーを追い立てる危険があり、理解速度を優先する中心思想と衝突し得るため。
